## 一、今天遇到的三个问题

### 问题1：机器人到点后疯狂旋转（"乱转"）

**现象**：机器人到达目标点附近后，不停原地旋转，特别是 ground_4 点。

**我最初以为的原因**：朝向没对准，需要加朝向精修。

**真正的原因**：我自己改了 Nav2 配置，把 `yaw_goal_tolerance` 从 `3.14159` 改成了 `0.30`。

**解释**：
- `yaw_goal_tolerance` 是 Nav2 判断"朝向是否到位"的容忍角度
- `3.14159`（=π）表示**完全不检查朝向**，只要位置到了就算成功
- `0.30`（约17°）表示 Nav2 会努力把机器人旋转到精确朝向
- 麦克纳姆轮是全向底盘，**不需要对准朝向**，强制旋转就会乱转

**官方怎么做**：
```yaml
# nav2_ground_params.yaml
general_goal_checker:
  yaw_goal_tolerance: 3.14159   # 不检查朝向
```

**修复**：把 `yaw_goal_tolerance` 改回 `3.14159`。

---

### 问题2：机器人没有完全进入方块就走

**现象**：机器人到达目标点附近，但没有完全进入 40×55cm 的任务方块，就去下一个点了。

**原因**：Nav2 的位置容差太大，送到点附近就判定成功，但其实离中心点还有距离。

**官方怎么做**：
- Nav2 位置容差 `xy_goal_tolerance: 0.04`（4厘米）
- Nav2 到位后，代码再做一次"精修"，把机器人精确挪到中心点
- 精修到位判定用 `dist < 0.05`（2D距离小于5厘米）

**精修的关键代码逻辑**：
```python
# 1. 计算当前位置到目标点的误差
err_x = target_x - current_x
err_y = target_y - current_y
dist = sqrt(err_x² + err_y²)

# 2. 如果距离小于容差，停止
if dist < 0.05:
    publish(stop)
    return

# 3. 否则按比例发速度指令（带最小速度地板）
vx = kp * err_x
vy = kp * err_y
# 如果速度太小，用最小速度保证能移动
if speed < min_speed:
    vx = min_speed * err_x / dist
    vy = min_speed * err_y / dist

# 4. 世界坐标转机体坐标（麦克纳姆轮可以侧移）
body_x = cos(yaw) * vx + sin(yaw) * vy
body_y = -sin(yaw) * vx + cos(yaw) * vy

# 5. 发布到 /cmd_vel
cmd.linear.x = body_x
cmd.linear.y = body_y
publish(cmd)
```

### 问题3：机器人到点后不动（不精修）

**现象**：Nav2 到位后，机器人就停了，没有执行精修。

**我最初的做法**：用 tf2 查 `map → base_footprint` 变换来获取当前位置。

**问题**：tf2 的 buffer 可能还没收到变换数据，`lookup_transform` 抛异常，返回 None，精修就跳过了。

**官方怎么做**：直接订阅 `/odom` 话题，用 odom 坐标做精修。

**为什么可以用 odom**：仿真环境中 `map` 和 `odom` 坐标系基本重合（静态变换），目标点坐标（如 1.125, -1.350）可以直接和 odom 坐标比较。

**修复**：精修改用 `self.ground_odom`（订阅 `/odom` 得到的数据），不用 tf2。

## 二、对比官方实现学到的东西

官方代码在 `/home/yjh/ican/inspection_ws/src/ican_inspection_mission/`

### 1. 航点朝向全部是 0

```python
# 官方 mission_manager.py 第318行
self.patrol.start_goal(x, y, 0.0)  # yaw 永远是 0
```

我之前给 ground_3/4 设了 `yaw=π/2`，以为方块是竖放的需要转90°。其实不需要——麦克纳姆轮可以侧移进去，不需要转身。

### 2. 精修只调位置，不调朝向

```python
# 官方 _publish_ground_fine
t.linear.x = ...   # 只发前进/后退
t.linear.y = ...   # 只发左移/右移
# 不发 t.angular.z （不旋转）
```

### 3. 有"最小速度地板"

```python
if speed < min_speed:  # min_speed = 0.1
    # 按误差方向给一个最小速度，保证机器人能挪动
    vx = min_speed * err_x / dist
    vy = min_speed * err_y / dist
```

没有这个的话，离目标很近时 `kp*err` 算出的速度太小，机器人摩擦力大于动力，就不动了。

### 4. 到位后保持一段时间

```python
arrival_hold_time = 1.5  # 到位后停1.5秒再走
```

防止机器人还没停稳就去下一个点。

## 三、关键概念速查

### 坐标系

| 坐标系 | 数据来源 | 用途 |
|--------|---------|------|
| `map` | Nav2 目标点、tf 变换 | 全局导航 |
| `odom` | `/odom` 话题 | 里程计，精修用 |
| `base_footprint` | 机器人底盘中心 | 机器人自身 |

仿真中 `map ≈ odom`，可以直接用 odom 坐标和目标点比较。

### 麦克纳姆轮

- 可以**全向移动**（前后左右斜着走），不需要旋转
- AMCL 必须配置：`robot_model_type: "nav2_amcl::OmniMotionModel"`
- 速度指令 `linear.x` 是前后，`linear.y` 是左右

### Nav2 重要参数

```yaml
general_goal_checker:
  xy_goal_tolerance: 0.04        # 位置容差 4cm
  yaw_goal_tolerance: 3.14159    # 不检查朝向（关键！）

FollowPath:
  xy_goal_tolerance: 0.04
  trans_stopped_velocity: 0.10
  short_circuit_trajectory_evaluation: true
```

## 六、踩坑总结

1. **不要随便改 Nav2 参数**，特别是 `yaw_goal_tolerance`，改小了会乱转
2. **麦克纳姆轮不需要旋转朝向**，航点 yaw 全设 0 就行
3. **精修用 /odom 就行**，不用搞 tf2 那么复杂
4. **一定要有最小速度地板**，不然离目标近了就不动了
5. **改了 yaml 配置要重启 Nav2**，不然不生效
6. **遇到问题先看官方实现**，比自己瞎调快得多
