# iCAN 城市应急全域巡检仿真环境接口说明

## 启动

```bash
cd <ican_inspection_user_ws>
source scripts/setup_env.sh
bash scripts/run_inspection_env.sh
```

该脚本只启动 Gazebo 仿真场景和地面 Nav2。

## 已提供内容

| 内容 | 说明 |
| --- | --- |
| Gazebo 世界环境 | 任务一巡检场地、外墙、指挥中心、地面巡检点、窗口障碍、空中巡检点 |
| 两栖陆空无人机模型 | 同一模型支持地面麦克纳姆轮移动和空中速度控制 |
| 地面传感器 | `/scan`、`/camera/image`、`/odom`、TF |
| 空中传感器 | `/uav/camera/image`、`/uav/lidar/points`、`/uav/laser/scan`、`/uav/odom` |
| 地面导航 | Nav2 地图、AMCL、规划器、控制器、RViz 配置 |
| 最小模板 | `ican_inspection_examples/minimal_user_node.py` |

## 基础控制接口

| 名称 | 类型 | 方向 | 说明 |
| --- | --- | --- | --- |
| `/cmd_vel` | `geometry_msgs/msg/Twist` | 发布 | 地面麦克纳姆轮速度控制，使用 `linear.x`、`linear.y`、`angular.z`。 |
| `/odom` | `nav_msgs/msg/Odometry` | 订阅 | 地面里程计。 |
| `/scan` | `sensor_msgs/msg/LaserScan` | 订阅 | 地面二维雷达。 |
| `/camera/image` | `sensor_msgs/msg/Image` | 订阅 | 地面前向相机。 |
| `/camera/camera_info` | `sensor_msgs/msg/CameraInfo` | 订阅 | 地面相机内参。 |
| `/uav/cmd_vel` | `geometry_msgs/msg/Twist` | 发布 | 飞行速度控制，使用 `linear.x/y/z` 和 `angular.z`。 |
| `/uav/odom` | `nav_msgs/msg/Odometry` | 订阅 | 飞行里程计。 |
| `/uav/camera/image` | `sensor_msgs/msg/Image` | 订阅 | UAV 前向相机。 |
| `/uav/camera/camera_info` | `sensor_msgs/msg/CameraInfo` | 订阅 | UAV 相机内参。 |
| `/uav/lidar/points` | `sensor_msgs/msg/PointCloud2` | 订阅 | UAV 前向 3D 点云。 |
| `/uav/laser_fire` | `std_msgs/msg/Bool` | 发布 | UAV 下方激光开关。 |
| `/uav/laser_state` | `std_msgs/msg/Bool` | 订阅 | UAV 下方激光状态。 |
| `/uav/laser/scan` | `sensor_msgs/msg/LaserScan` | 订阅 | UAV 下方单线测距。 |


## 飞行速度控制示例

飞行阶段目前提供底层速度接口 `/uav/cmd_vel`。最小模板默认演示开环速度控制，不使用航点闭环函数：

- 持续发布正 `linear.z`，让 UAV 上升
- 持续发布正 `linear.x`，让 UAV 前进
- 持续发布全 0 速度，保持悬停
- 持续发布负 `linear.z`，让 UAV 下降
- 最后发布全 0 速度停止

这是最小接口示例，不包含定位闭环、避障或完整空中全局路径规划。需要精准到点时，用户可以订阅 `/uav/odom` 后自行实现 PID、MPC 或其他控制器。

## 常用命令

```bash
ros2 topic echo /odom
ros2 topic echo /uav/odom
ros2 topic echo /uav/camera/image
ros2 topic pub /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.2, y: 0.0, z: 0.0}, angular: {z: 0.0}}" -r 10
ros2 topic pub /uav/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: 0.0, z: 0.1}, angular: {z: 0.0}}" -r 10
ros2 topic pub --once /uav/laser_fire std_msgs/msg/Bool "{data: true}"
ros2 topic pub --once /uav/laser_fire std_msgs/msg/Bool "{data: false}"
```
